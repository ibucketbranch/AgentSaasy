The two failures, examined

Only one survives scrutiny, which is why the run is treated as a failed calibration despite the nominal gate pass.

Q1 retrieval · nano run 2 confirmed miss

The answer listed all five required critical assets with correct details but never stated the total count of 12. The tightened rubric requires the count explicitly. A genuine, if narrow, failure.

Q2 analytical · nano run 2 judge noise

The judge returned FAIL while its own notes read: "PUMP-003 and HVAC-007 are ranked first and second correctly, quantitative signals cited, no fabricated numbers — actually all criteria are met." A self-contradicting verdict, same failure class as the haiku judge errors in Grid-1, now in opus at lower frequency. Amendment v1.1 adds a fail-confirmation protocol: every FAIL gets an independent second opinion, majority rules on disagreement.

Next: amendment v1.1 (drafted, pending approval) removes the giveaway hint from Q4, adds a trap that punishes blanket rejection (FAN-012 genuinely belongs on the critical list), makes Q5 a three-step derivation with non-round numbers, then recalibrates.
