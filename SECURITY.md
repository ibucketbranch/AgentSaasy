# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting on this repository
(Security tab > Report a vulnerability). Reports go directly to the
maintainer and are acknowledged within 72 hours.

If private reporting is unavailable to you, contact the maintainer
through bucketbranch.ai.

## Scope

- The agent code, tools, and demo scripts in this repository.
- The bundled demo data is synthetic. If you believe any non-synthetic
  or sensitive data has entered the repository or its history, report
  it through the channel above; that is treated as a security issue.

## Out of scope

- Vulnerabilities in third-party model providers or their APIs.
- The private reference infrastructure this repo's published results
  were produced on.

## Supported versions

The `main` branch. No backports.
