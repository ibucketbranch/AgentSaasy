### Published Research

**AEQ (Agent Efficiency Quotient)** is a measurement framework for AI agent architecture quality: business value delivered over tokens consumed. Two agents, same model, same question, same answer. One spent 4.68x the tokens.

| Artifact | What it is |
|----------|------------|
| [**AEQ specification and run records**](https://github.com/ibucketbranch/AEQ) | Spec v1.1, the pre-registration series, every run record, and an 11-entry ledger of defects the method caught in itself |
| [**The Cost of a Question**](https://bucketbranch.ai/papers/cost-of-a-question/) | White paper. What a per-seat license buys, measured against what the compute actually costs |
| [**Same Model, Same Question, 4.68x the Tokens**](https://medium.com/@michael_valderrama/same-model-same-question-4-68x-the-tokens-455725b06add) | The method in plain terms, on Medium |
| [**The Agentic Loop, as an Economics Problem**](https://bucketbranch.ai/reference/agent-loop-economics/) | One-page reference for operators |

Method notes: rubrics locked before every run, cross-family judging so no vendor's model grades its own output, and prices sourced and dated rather than estimated.
