Same model, two precisions: what did compression actually cost?

Completed 2026-07-24 06:05 UTC Parent llama3.2:3b fp16 (6.4 GB) Quantized llama3.2:3b Q4_K_M (2.0 GB) Reference gpt-5.2 · Judge opus-4-8 Mac mini M4 · Ollama
Result RED per locked gates Quantization cost: zero

The registered verdict is RED: aggregate pass rate for the two local tiers was 10%, far under the 40% floor, exactly the floor effect the v1.2 amendment predicted for a 3B model against a frontier-calibrated rubric.

The finding inside the RED: the quantized copy passed 3 of 15 cells; its own full-precision parent passed 0 of 15. Compression did not degrade this model on this workload; the 3.2x-smaller, 2.3x-faster Q4 build did everything the fp16 build did and aced the derived-math class the fp16 fabricated. At this scale the model is the limit, not the precision, and the certification instrument caught every failure either way.

Flags for the record

Frontier integrity dipped below the floor this run: 12/15 vs the 13 floor

gpt-5.2 fell for the CHIL-005 trap in both counted Q4 runs (plus one empty answer). Across runs the frontier's Q4 record is now 2/3, 2/3, 0/2: the urgent-note-vs-threshold trap fools even the reference model regularly. Either the rubric's strict reading stands (the definition is explicit in the evidence) and this is a genuine frontier weakness worth publishing, or the trap is ambiguous enough that a v1.3 wording pass should sharpen it. Decision belongs to the author before publication.

The OpenAI models in this experiment series are deprecated

Verified against official pages on 2026-07-24: gpt-5.2 shuts down 2026-08-10 (weeks away); gpt-5-mini and gpt-5-nano on 2026-12-11. Before the white paper ships, the headline experiments should be re-run on current models (gpt-5.6 family), both for verifiable pricing and so a skeptic can reproduce them.
